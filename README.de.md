# dskripchenko/laravel-admin-media

> 🌐 [English](README.md) · [Русский](README.ru.md) · **Deutsch** · [中文](README.zh.md)

Erweiterte Medienbibliothek: Collections, Tags, Focal-Point, responsive Varianten, EXIF-Stripping. Keine spatie/medialibrary-Abhängigkeit.

Ein Sister-Pack für [`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin).

## Installation

```bash
composer require dskripchenko/laravel-admin-media
php artisan migrate
```

Das Plugin registriert sich automatisch über Laravel Package Discovery.
