# dskripchenko/laravel-admin-media

> 🌐 [English](../../README.md) · [Русский](../ru/README.md) · [Deutsch](../de/README.md) · **中文**

扩展媒体库：collections、tags、focal-point、响应式变体、EXIF 剥离。无 spatie/medialibrary 依赖。

[`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin) 的姐妹包。

## 安装

```bash
composer require dskripchenko/laravel-admin-media
php artisan migrate
```

插件通过 Laravel package discovery 自动注册。
